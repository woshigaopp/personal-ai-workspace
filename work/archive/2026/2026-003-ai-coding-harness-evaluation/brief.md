# 任务说明

## 背景

用户将该项目视为自己对 AI Coding 的完整理解及一个“大 Skill”，希望客观判断其是否真正有价值。

## 目标

理解方法论与实现，区分思想价值、领域价值、通用 Skill 价值和已验证价值，并给出最关键的改进与验证路径。

## 范围

包含仓库主入口、方法论、阶段 Skill、模板、运行时 manifest、validators 和 smoke validation；不对 AutoMQ 私有飞书原始材料及未公开真实项目 artifact 做真实性审计。

## 完成标准

- [x] 阅读方法论和工作流核心入口
- [x] 运行仓库校验
- [x] 判断核心贡献与非原创部分
- [x] 识别泛化、复杂度和证据风险
- [x] 给出可证伪的下一步评估方案
