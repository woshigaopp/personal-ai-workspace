# 资料来源

访问日期均为 2026-08-17。

## 来源

### 1. 2025 Stack Overflow Developer Survey — AI

- 链接：https://survey.stackoverflow.co/2025/ai
- 作者或机构：Stack Overflow
- 支持的结论：AI 工具已广泛采用，但 Agent 尚未完全主流；72% 受访者不进行 vibe coding；准确性与安全仍是主要顾虑。
- 可靠性或局限：大样本开发者调查，但为自报数据且存在抽样与术语理解差异。

### 2. Introducing the Codex app

- 链接：https://openai.com/index/introducing-the-codex-app/
- 作者或机构：OpenAI
- 支持的结论：前沿交互正从单 Agent 配对转向并行监督多个 Agent，并通过 worktree 隔离任务。
- 可靠性或局限：产品方一手资料，能证明能力与产品方向，不能独立证明全行业采用度。

### 3. Harness engineering: leveraging Codex in an agent-first world

- 链接：https://openai.com/index/harness-engineering/
- 作者或机构：OpenAI
- 支持的结论：Agent-first 工程的核心是规格、可读环境、工具、反馈回路、隔离执行和 Agent 间评审，而不只是更强的模型。
- 可靠性或局限：真实内部案例，但属于前沿单一案例，不能直接外推到所有团队。

### 4. About third-party coding agents

- 链接：https://docs.github.com/en/copilot/concepts/agents/about-third-party-coding-agents
- 作者或机构：GitHub
- 支持的结论：异步任务到 PR、人工评论后继续迭代，已成为主流平台支持的标准工作流。
- 可靠性或局限：官方产品文档，反映可用工作流，不代表采用率。

### 5. About GitHub Agentic Workflows

- 链接：https://docs.github.com/en/enterprise-cloud@latest/copilot/concepts/agents/about-github-agentic-workflows
- 作者或机构：GitHub
- 支持的结论：事件驱动、自然语言定义、最小权限和安全输出的仓库自动化已出现，但仍处于 public preview。
- 可靠性或局限：官方预览文档，能力与接口可能变化。

### 6. State of AI-assisted Software Development 2025

- 链接：https://dora.dev/research/2025/dora-report/
- 作者或机构：Google Cloud DORA
- 支持的结论：AI 更像组织能力的放大器，收益依赖既有工程系统，而非工具本身。
- 可靠性或局限：跨组织研究，但结论是组织层面的相关性与综合判断。
